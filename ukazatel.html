Горячие клавиши
  • / — поиск по странице; Enter — следующее совпадение
  • Ctrl/Cmd+E — поиск по всем справочникам (@ — разделы)
  • Ctrl/Cmd+E — в палитре вниз, +Shift — вверх
  • Ctrl/Cmd+Shift+P — палитра команд: что можно сделать
  • [ ] — предыдущий / следующий раздел
  • j / k — скролл вниз / вверх
  • g g — в начало страницы
  • G — в конец страницы
  • t — скрыть оглавление
  • n — показать/скрыть навигацию
  • z — Zen-режим: только текст
  • y — ссылка на раздел
  • Esc — очистить поиск и снять фокус; в Zen — выйти
